# VoltRoad — Smart Dynamic Wireless EV Charging Roads

Interactive React + Vite website based on the supplied Vishwakarma Awards Stage 2 presentation.

## Included
- Responsive landing page
- Animated road/coil visual
- Interactive vehicle-position charging simulator
- System architecture section
- Prototype specifications
- Safety and fail-safe section
- Indicative BOM
- 4-month fabrication roadmap
- Mobile navigation
- GitHub/Vercel-ready Vite structure

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for deployment

```bash
npm run build
```

The production files will be in `dist/`.

## Deploy to Vercel
Import this project/repository into Vercel. Framework preset: Vite.

## Deploy to GitHub
Push the folder to a GitHub repository, then deploy it using Vercel, Netlify, or GitHub Pages.

## Important
The website treats figures from the presentation as design targets/indicative values, not measured prototype results. Replace them with your team's actual measurements before using the site as final technical evidence.
